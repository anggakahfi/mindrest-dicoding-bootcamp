# Tech Stack — TweetMind

## Frontend
| Teknologi | Fungsi |
|---|---|
| Next.js 16 (App Router) | Framework React fullstack dengan routing built-in |
| TypeScript | Type safety |
| Tailwind CSS 4 | Styling dan responsivitas |
| shadcn/ui (Radix UI) | Komponen UI reusable (Button, Card, Input, Toast, dll) |
| Recharts | Visualisasi grafik progres stres 7 hari |
| Lucide React | Icon library |
| next-themes | Dark/light mode |

## Backend
| Teknologi | Fungsi |
|---|---|
| Node.js + Express 5 | REST API utama aplikasi |
| TypeScript | Type safety |
| JWT (jsonwebtoken) | Autentikasi dan manajemen session |
| bcryptjs | Enkripsi password |
| MongoDB Atlas | Database cloud (koleksi: users, daily_checkins, predictions) |
| Mongoose 9 | ODM untuk interaksi dengan MongoDB |
| express-validator | Validasi input request |

## AI Service
| Teknologi | Fungsi |
|---|---|
| Python + FastAPI | REST API serving model ML |
| TensorFlow + Keras | Membangun dan melatih model klasifikasi teks |
| TensorBoard | Monitoring metrik training |
| Google Gemini API | Generasi saran relaksasi personal |

## Data Science
| Teknologi | Fungsi |
|---|---|
| Pandas + NumPy | Data wrangling dan preprocessing |
| Matplotlib + Seaborn | Visualisasi EDA |
| SciPy | A/B Testing (uji T-Test) |
| Streamlit | Dashboard analitik interaktif |

## Infrastruktur
| Layanan | Fungsi |
|---|---|
| Vercel | Hosting frontend |
| Render.com | Hosting backend Express dan FastAPI |
| Streamlit Community Cloud | Hosting dashboard DS |
| GitHub | Version control dan penyimpanan log TensorBoard |
